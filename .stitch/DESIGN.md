## Overview

**A Inventory**(AI + Inventory, 앱 식별자 `Ainventory`)는 내 옷을 사진 한 장으로 디지털화하고, **AI로 생성한 나만의 모델**에게 날씨와 일정에 맞는 착장을 입혀 보는 **프라이빗 피팅 스튜디오**다. 웹(GitHub Pages)과 Capacitor Android에서 동일하게 동작하는 모바일 우선 앱이며, 모든 제품 카피는 한국어로 작성한다.

### Design Core — "Maison Gold Editorial" (v4)

v4부터 디자인 코어는 **패션 하우스의 감각**이다. 하이엔드 메종의 룩북·캠페인·부티크 로그인(RIMOWA, BORO 레퍼런스)처럼 *여백이 말하고, 타이포가 옷을 입고, 금빛 한 점이 시선을 붙잡는* 화면을 만든다. 크롬은 여전히 무채색이지만, **Maison Gold 단 하나**가 라이트·다크 모두에서 브랜드의 서명(signature) 역할을 한다.

### Brand Mood — 5 Adjectives

| 형용사 | 의미 | 화면에서의 구현 |
| :--- | :--- | :--- |
| **Editorial** (에디토리얼) | 패션 매거진 지면처럼 큰 여백·대비가 분명한 타이포·한 화면 한 메시지 | 브랜드 화면은 세리프 `editorial-display`/워드마크, 유틸리티 화면은 `screen-title` 1개 + `kicker`. 장식 아이콘·배지 최소화 |
| **Sensual** (감각적) | 실크가 흐르고 조명이 스치는 듯한 관능적 움직임 | 로그인 실크 파이버 캔버스·런웨이 스포트라이트, 1.2s 쿠튀르 커브 리빌, 금빛 글린트 |
| **Tailored** (테일러드) | 재단선처럼 정확한 그리드와 날카로운 모서리 | 브랜드 서피스는 `couture` 2px 반경·1px 헤어라인·언더라인 필드, 8pt 그리드 |
| **Quiet Luxury** (조용한 럭셔리) | 로고보다 소재, 소리치지 않는 고급스러움 | 금색은 포인트로만(≤ 화면 면적 5%), 경고는 1줄 캡슐, 다크 모드는 OLED 순흑 위의 정적 |
| **Tactile** (촉각적) | 원단과 종이를 만지는 듯한 물성 | 스쿼클 카드 키라이트·스펙큘러 림, 그레인 텍스처, 탭 시 `scale(0.97)`, 햅틱 `selection` |

### Brand Surfaces vs Utility Surfaces
- **Brand surfaces** (로그인·인트로·스플래시·온보딩·빈 상태 히어로): 패션 하우스 문법. 세리프/와이드 트래킹 워드마크, `couture` 2px 반경, 언더라인/박스 필드, 금색 CTA, 모션 배경 허용.
- **Utility surfaces** (옷장·코디·캘린더·통계·시트): 기존 Apple HIG 미니멀 문법(스쿼클·필·글래스 HUD)을 유지하되, 포인트 컬러는 샌드 대신 **금색**을 사용한다(착용 링·큐레이션 점·활성 인디케이터).

### Spatial Philosophy — "Gallery, Not Dashboard"
1. **옷과 사람이 주인공이다.** 화면 면적의 85% 이상(`minVisualRatio: 0.85`)은 의류 이미지·AI 모델·여백이 차지하고, 크롬(컨트롤)은 가장자리 글래스 HUD로 물러난다.
2. **세 개의 깊이 평면만 사용한다.** ① 캔버스(벽) ② 표면(카드·스테이지 — 바닥) ③ 플로팅 글래스(HUD·시트·탭 독 — 공중). 그 외 임의의 중간 평면·중첩 카드 금지.
3. **점진적 공개.** 1차 동작만 상시 노출하고, 2차 필터·고급 설정은 사용자가 맥락에 들어설 때(카테고리 선택, AI 모델 활성화) 슬라이드로 드러낸다.
4. **고정된 무대, 바뀌는 조명.** 상태가 바뀌어도 무대(레이아웃 박스)는 움직이지 않고, 조명(불투명도·블러·쉬머)과 내용만 바뀐다 → Zero-CLS.
5. **어둠은 비어 있음이다.** 다크 모드의 배경은 OLED 픽셀이 완전히 꺼지는 `#000000`. 빛(텍스트·금색·옷)만 화면에 남겨 쇼룸 조명 같은 집중을 만든다.

## Brand Identity — A Inventory Logo

### Concept
- 이름 = **AI + Inventory**. 워드마크는 `A INVENTORY`로 표기하고, **A와 I(= "AI")만 금색**, 나머지 `NVENTORY`는 잉크색이다. "AI가 옷장을 정리한다"는 의미가 글자 색만으로 읽힌다.
- **모노그램**: 옷걸이 후크가 달린 삼각형이 `A`가 되고(가로 크로스바 = 옷걸이 바), 그 옆에 가는 `I`가 선다. 두 글자 모두 금색 스트로크(1.5–2px @ 48px). Maison 버전은 `I`에 세리프, Runway 버전은 원형 프레임(링) 안에 배치.

### Variants
| Variant | Wordmark | Monogram | Layout | 사용처 |
| :--- | :--- | :--- | :--- | :--- |
| `maison` | Bodoni Moda 500, tracking `0.2em` | 세리프 I | `stacked` (모노그램 위, 워드마크 아래) | LOOK 01 로그인, 스플래시, 공식 문서 |
| `runway` | Jost 500, tracking `0.42em` | 산세리프 I + 1px 링 프레임 | `inline` (모노그램 좌, 워드마크 우) | LOOK 02 로그인, 앱 헤더, 소셜 썸네일 |

### Rules
- 색: 라이트 `AI` = `#B08D57`, 나머지 = `#0A0A0A` / 다크 `AI` = `#D4AF6A`, 나머지 = `#F5F2EA`. 금색 대신 다른 색으로 `AI`를 칠하거나 전체를 금색으로 칠하지 않는다.
- 여백(clear space): 모노그램 높이의 50% 이상. 최소 크기: 모노그램 24px, 워드마크 cap-height 10px.
- 접근성: 로고 루트는 `role="img"` + `aria-label="A Inventory"`(언어 무관 영문). 장식 SVG는 `aria-hidden`.
- 모션: 인트로에서 스트로크 드로잉(`stroke-dashoffset`, 1.4s 쿠튀르 커브) 후 워드마크 페이드. `prefers-reduced-motion`에서는 정지 상태로 즉시 표시.
- 컴포넌트: `<AInventoryLogo variant layout framed animateDraw />` 외 임의 재조합 금지.

## Layout

### 8pt Grid
- 기본 단위 `8px`. 허용 간격 스케일은 **`4 · 8 · 16 · 24 · 32 · 40 · 48`** (`--space-1 … --space-12`) 뿐이다. `2px/3px/5px/6px/10px/12px` 등 스케일 밖 간격 신규 도입 금지(4px는 아이콘-라벨 사이 등 미세 간격 전용).
- 화면 거터: 모바일 `16px` / 태블릿 `24px` / 데스크톱 `40px`. Galaxy Z Fold 커버(`≤ 359px`)만 `12px` 예외.
- 섹션 간 수직 리듬: 섹션 사이 `32px`, 섹션 제목과 내용 `16px`, 카드 내부 `16px`(통계 벤토 `24px`).

### Touch Targets
- 모든 인터랙티브 요소의 히트 영역 **≥ 48×48dp** (시각 크기가 작아도 패딩/의사요소로 확장). 인접 타깃 간격 ≥ 8px.
- 예외 없음: 칩 해제 `×`, 히스토리 삭제, 캘린더 날짜 셀, 비밀번호 표시 토글 포함.

### Information Architecture (4-Tab)
1. **옷장 (`closet`)**: 타이틀 + 아이템 수 → 단일 카테고리 레일(전체·상의·하의·아우터·신발·액세서리·주얼리) → (선택 시) 서브파트 레일 → 스쿼클 그리드(2→3→4열). 검색·정렬은 헤더 아이콘에서 펼침.
2. **코디 (`outfits`)**: AI 모델 스튜디오 무대(리넨 사이클로라마) + 오브시디언 드로어. `≥ 600px` 58:42 분할, 모바일은 전체 무대 + 바텀시트 드로어.
3. **캘린더 (`calendar`)**: 월간 룩북 그리드(착장 썸네일 셀) + 슬라이드 오버 데이 드로어.
4. **통계 (`stats`)**: 벤토 카드(대표 수치 → 차트 → 랭킹) 에디토리얼 그리드.

### Breakpoints & Safe Areas
- `≤ 359px` 폴드 커버 / `360–599px` 표준 모바일 / `≥ 600px` 태블릿·언폴드 / `≥ 1024px` 데스크톱(`max-width: 1160px`).
- `env(safe-area-inset-*)` 항상 준수. 하단 탭 독 여유 `calc(112px + var(--safe-bottom))`. 가로 오버플로 0.

## Motion — Zero-CLS Rules

- **커브**: `--spring-ease: cubic-bezier(0.32, 0.72, 0, 1)`. 지속시간: 마이크로 120–180ms, 전환 240ms, 시트 340–360ms.
- **애니메이션 허용 속성은 `opacity`, `transform`, `filter`, `clip-path` 뿐.** `height/width/top/margin` 애니메이션 금지.
- **예약 슬롯**: 조건부 UI(상태 캡슐, Staged CTA, 각도 독, 서브파트 레일)는 항상 고정 크기 컨테이너를 렌더하고 내부만 crossfade. 마운트/언마운트로 형제 요소를 밀어내지 않는다.
- **이미지 박스**: 모든 이미지 컨테이너에 `aspect-ratio` 명시. 로딩은 스켈레톤 쉬머(같은 크기).
- **숫자**: tabular-nums로 폭 고정, 카운트업 애니메이션 시에도 폭 불변.
- **상태 전환 매트릭스 (Outfits)**: 플랫레이 ↔ 생성 중 ↔ AI 모델 뷰 ↔ 피부톤/체형 시트 — 무대 박스 크기·HUD 위치 변화 0px, 바뀌는 것은 무대 내용(crossfade 240ms)과 HUD 내용뿐.
- `prefers-reduced-motion: reduce` → 쉬머·스윕·파티클 정지, crossfade만 120ms.

### Brand Motion (v4 — 로그인·인트로)
- **쿠튀르 커브** `--lx-ease-couture: cubic-bezier(0.76, 0, 0.24, 1)` — 원단이 천천히 들렸다가 내려앉는 느낌. 리빌·로고 상승 1.2s 전용.
- **라이즈 커브** `--lx-ease-rise: cubic-bezier(0.22, 1, 0.36, 1)` — 요소 등장 0.6–0.8s.
- **배경 모션 예산**: 캔버스는 DPR 최대 2, 60fps 목표·`requestAnimationFrame` 1개, 탭이 숨겨지면(`visibilitychange`) 정지, 감소 모션에서는 정지 프레임 1장. CSS 무한 애니메이션은 `transform`/`opacity`만.
- **E2E 안정성**: 무한 반복 애니메이션은 테스트의 "애니메이션 종료 대기" 대상에서 제외된다(`iterations === Infinity` 필터) — 무한 루프 모션은 반드시 `animation-iteration-count: infinite`로 선언.
- 인트로 로고 드로잉 1.4s → 워드마크 페이드 0.8s(0.6s 지연) → 태그라인 0.8s(1.0s 지연) → 진행 라인 3.2s.

## Do's and Don'ts

### Do's
- 크롬은 무채색(`#FFFFFF`/`#F5F5F7`/`#1D1D1F`, 다크 `#000000`/`#1C1C1E`/`#F5F5F7`) + **Maison Gold 포인트 1색**. 나머지 색은 옷·피부·날씨에서만.
- 다크 모드 배경은 OLED 순흑 `#000000`을 넓게 쓰고, 깊이는 그래파이트 표면 단차와 헤어라인으로.
- 금색 채우기 위에는 항상 `#0A0A0A` 텍스트, 라이트 모드 금색 텍스트는 `#8C6A3A`만.
- 로고는 `AInventoryLogo` 컴포넌트로만, `AI`만 금색.
- 모든 수치에 `tabular-nums`, 모든 타깃 48dp, 모든 간격 8pt 스케일.
- 상태는 1줄 캡슐로 조용히, 다음 행동은 하나의 명확한 CTA로.
- 조건부 UI는 예약 슬롯에서 crossfade (Zero-CLS).
- 모든 카피는 자연스러운 한국어(숫자·단위·브랜드명만 예외), 기술 용어(누끼, 크레딧, V7, reason code) 사용자 노출 금지.
- `html[data-vibrancy-fallback='solid']`, `prefers-reduced-motion`, `prefers-reduced-transparency`, safe-area 항상 지원.

### Don'ts
- 붉은 점·붉은 박스로 정보성 상태(API 키 미설정 등)를 알리지 않는다.
- 플랫레이 룩북에 3D 각도 컨트롤을 노출하지 않는다.
- 같은 의미의 필터 축을 두 줄 이상 동시에 노출하지 않는다.
- 금색을 메탈릭 그라디언트·대형 배경·본문 텍스트로 쓰지 않는다(포인트 ≤ 5%). 보라-파랑 그라디언트·네온 액센트 금지.
- 라이트 모드에서 `#B08D57`을 작은 텍스트(< 24px)에 쓰지 않는다(3.09:1 미달) — `#8C6A3A` 사용.
- 다크 모드 배경을 `#141413`·`#121212` 같은 근흑으로 되돌리지 않는다(스튜디오 오브시디언 무대·드로어 등 "떠 있는 표면"은 예외).
- 로그인 인트로 중 폼을 조작 가능하게 두지 않는다(`inert`), 리빌에서 `top/height`를 애니메이션하지 않는다.
- 라이트 모드 Outfits 스테이지를 어둡게 만들지 않는다.
- 날씨 오버레이 위에 HUD 없이 텍스트를 직접 올리지 않는다.
- 임의 반경(9/11/12/13/18px), 스케일 밖 간격(2/3/5/6px)을 새로 도입하지 않는다.
