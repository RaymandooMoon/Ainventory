# iNVTRY IR 사업계획서 v6.0 — 창업자 입력 요청서 (`FOUNDER_INPUTS.md`)

> **작성 목적**: 독립 검토 보고서(v5.4 → v6.0)의 절대 원칙에 따라, **투자액 · 지표 · 원가 · 단가 · 이력 · 법인 정보 · 정책은 창업자가 확정한 값만** 데크에 반영합니다.
> 아래 항목 중 아직 확정되지 않았거나 미수신된 값은 데크 본문에 `[TBD]`나 `[기입 예정]`을 남기지 않고 **제외하거나 `"협의 후 공유"`로 표기**해 두었습니다.
> 확정되는 항목부터 회신해 주시면 즉시 v6.0 데크 및 동기화(`npm run ir:sync`)에 반영하겠습니다.
