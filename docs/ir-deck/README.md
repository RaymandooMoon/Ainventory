# iNVTRY (Ainvtry) IR 사업계획서 데크 (`docs/ir-deck/`) — v2.0 (18장)

TIPS · 도전의IR · VC 투자 제안서 표준을 반영한 **18슬라이드 듀얼 비율(`16:9` & `4:3`) HTML IR 사업계획서**입니다.

## 주요 특징
- **듀얼 비율 네이티브 전환**: 상단 툴바 또는 URL 쿼리(`?ratio=16-9` / `?ratio=4-3`)로 `16:9` (`1280×720`)와 `4:3` (`1024×768`)을 왜곡·잘림 없이 실시간 전환하며, 인쇄 시 `@page` 규격도 자동 연동됩니다.
- **듀얼 테마**: VC 제출·인쇄 기본 테마인 **Light Editorial Ivory**와 현장 발표용 **Dark OLED Runway** 모드를 지원하며, 공식 로고 및 실제 한국어 앱 스크린샷 4종이 테마에 맞춰 자동 교체됩니다.
- **4파트 18장 완결 구성**:
  - `01` 표지 · `02` 목차(클릭 즉시 이동)
  - `PART 01 (03–05)` Executive Summary · 6대 파편화된 페인포인트 · 6→1 단일 OS 일괄 해결 매트릭스
  - `PART 02 (06–09)` 6컷 사용자 여정 · 실구동 앱 4화면 · 핵심 기술(`582KB→23KB`) · 4대 데이터 보안 방어선
  - `PART 03 (10–13)` 시장 규모(TAM/SAM/SOM) · 2×2 경쟁 포지셔닝 · **BM ① 4중 수익 모델 & 티어** · **BM ② 플라이휠 & AI 단위경제학**
  - `PART 04 (14–17)` 개발 실적 & 6-Tier · GTM 18개월 로드맵 · 팀 & 거버넌스 · 투자 제안 & 마일스톤
  - `18` 감사합니다 (Closing & Live 3D Demo)

## 열람 방법
1. **오프라인 직접 열람**: 로컬 저장소에서 `docs/ir-deck/index.html`을 Chrome/Safari로 더블클릭합니다.
2. **URL 파라미터 예시**:
   - `index.html?ratio=16-9&theme=light&view=deck`
   - `index.html?ratio=4-3&theme=dark&view=scroll`
3. **키보드 단축키**: `←` / `→` / `Space` / `Home` / `End` (목차 슬라이드 각 항목 클릭 시 해당 페이지로 즉시 이동)
