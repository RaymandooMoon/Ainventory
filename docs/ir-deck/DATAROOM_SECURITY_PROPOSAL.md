# iNVTRY 투자자 데이터룸 보안 개선 제안서 (`DATAROOM_SECURITY_PROPOSAL.md`)

> **문서 성격**: 본 문서는 IR 독립 검토 지적 **C13 (P5)**에 따라 작성된 **운영 조치 가이드 및 고도화 제안서**입니다.
> 즉시 반영이 필요한 게이트 화면 문구 삭제·고지 추가는 [`worker/investorShield.js`](../../worker/investorShield.js)에 이미 적용 완료되었으며, 아래 **§2 투자자별 개별 코드 · 만료 · 워터마크 기능**은 창업자 승인 후 별도 구현할 제안안입니다.

---

## 1. 즉시 실행 필요: `IR_ACCESS_PASSCODE` 접근 코드 교체 절차

기존 게이트 화면에 안내 문구가 노출되어 있던 이력을 해소하기 위해, 프로덕션 Cloudflare Workers 시크릿을 **추측 불가능한 고엔트로피 값**으로 교체해야 합니다.

### 실행 명령어 (창업자 로컬 터미널 또는 Cloudflare Dashboard)
```bash
# 1) 고엔트로피 코드 생성 예시 (로컬에서만 확인, 절대 커밋·문서화·로그 출력 금지)
openssl rand -base64 18 | tr -d '/+=' | head -c 16

# 2) Cloudflare Workers 시크릿 갱신 (대화형 입력, 셸 히스토리에 남지 않음)
npx wrangler secret put IR_ACCESS_PASSCODE
```

### 보안 운영 수칙
- 접근 코드는 **최소 12자 이상 영문 대소문자·숫자 조합** (브랜드명·회사명·투자사명 등 사전 단어 배제)을 권장합니다.
- 코드 교체 직후 기존 세션 쿠키 무효화를 함께 원할 경우 `IR_SESSION_SECRET`도 함께 회전합니다 (`npx wrangler secret put IR_SESSION_SECRET`).
- 접근 코드는 Git 저장소, 이슈, PR, IR 문서, 슬랙 공용 채널에 절대 기록하지 않습니다.

## 2. 고도화 제안안 (구현 전 검토용): 투자자별 코드 · 만료 · 동적 워터마크

현재 단일 공용 코드(`IR_ACCESS_PASSCODE`) 방식은 간편하지만, **특정 링크가 외부로 재공유되었을 때 유출 경로를 특정하거나 개별 회수하기 어렵다**는 한계가 있습니다. 아래 3단계 경량 개선안을 제안합니다.

### 제안 A. 투자자별 개별 코드 & 라벨 관리 (Cloudflare KV / D1)
- **구조**: `NEWSLETTER_KV` 또는 `NEWSLETTER_DB`(D1)에 투자자별 초대 레코드 저장(원문 코드가 아닌 `SHA-256` 해시만 저장):
  ```json
  {
    "codeHash": "<sha256(salt + code)>",
    "investorLabel": "OO벤처스 · 김OO 심사역",
    "expiresAt": "2026-12-31T23:59:59Z",
    "revoked": false,
    "maxViews": 50
  }
  ```
- **효과**:
  1. 초대받은 투자사가 별도로 이름을 입력하지 않아도 **코드 자체로 열람자 자동 식별** (오입력·익명 우회 차단).
  2. 미팅 종료·보류 투자사만 **개별 코드 즉시 폐기(`revoked: true`)** 가능 (타 투자사 세션 무영향).
  3. 투자사별 열람 횟수·마지막 열람 시점 추적 가능.

### 제안 B. 초대 링크 만료(TTL) 및 세션 단축
- **만료 기간**: 초대 시점 기준 기본 **14일 만료**(TIPS 심사·투심위 기간에 맞춰 연장 가능).
- **세션 쿠키**: 현재 `12시간` (`HttpOnly; Secure; SameSite=Lax`) 유지 또는 `4시간` 단축 옵션 제공.

### 제안 C. 동적 비가시·저대비 워터마크 (HTML & PDF 인쇄 대응)
- **적용 방식**: Worker가 `/ir/index.html`을 서빙할 때 검증된 세션의 `investorLabel` + 열람 일시(`YYYY.MM.DD`)를 읽기 전용 메타로 주입하고, 데크 오버레이에 `opacity: 0.04` 수준의 미세 대각선 워터마크(`Confidential · OO벤처스 · 2026.11.28`)를 렌더링(인쇄/PDF 출력 CSS `@media print`에도 유지).
- **효과**: 스크린샷·PDF 무단 재배포 억제 및 유출 시 경로 식별.

### 구현 예상 공수 & 우선순위
| 항목 | 예상 공수 | 권장 시점 |
| :--- | :---: | :--- |
| `IR_ACCESS_PASSCODE` 즉시 교체 | 5분 | **즉시 (오늘)** |
| 제안 A+B (투자자별 코드 · 만료 · 개별 폐기) | 0.5일 | 시드/프리시드 본격 미팅 시작 전 |
| 제안 C (동적 저대비 워터마크) | 0.5일 | 외부 복수 VC 동시 배포 시점 |
